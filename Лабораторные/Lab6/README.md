# Лабораторная работа №6

## Выполненные проверки:

1. **statistics.py**: 
   * Ввод `-2 0 5 3` -> Количество: 4, Сумма: 6, Минимум: -2, Максимум: 5, Среднее: 1.50.
   * Ввод пустой строки -> Сообщение "Нет данных".

2. **transform.py**: 
   * Ввод `-2 0 5 -2` -> Исходный: `[-2, 0, 5, -2]`, Новый: `[2, 0, 5, 2]`. Исходные данные сохранены.

3. **positions.py**: 
   * Ввод `3 7 2 7` -> Вывод индексов: `[1, 3]`.
   * Ввод пустой строки -> Сообщение "Нет данных".

4. **variant.py (Вариант 8)**:

     Вывод: Выборка: `[]`, Количество: `0`, Сумма: `0`, Сортированная структура: `[]` (совпадает с условием, совпадений нет).
   * **Тест 2 (Собственный набор с совпадениями):** Ввод `5 12 25 10 15 8 20`  
     Вывод: Выборка: `[12, 10, 15, 20]`, Количество: `4`, Сумма: `57`, Сортированная структура: `[10, 12, 15, 20]`.
