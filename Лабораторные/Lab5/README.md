# Лабораторная работа №5


## Выполненные проверки:

1. ** normalize.py **: 

   * Ввод: `  Один   два  ` -> Вывод: `Один два`, слов 2, длина результата 8.
   * Ввод: пустая строка -> Исходная длина: 0, Новая длина: 0, слов 0.

2. ** palindrome.py **: 

   * Ввод: `А роза упала на лапу Азора` -> Вывод: Палиндром.
   * Ввод: `     ` (только пробелы) -> Вывод: Нет текста.
   * Ввод: `Python` -> Вывод: Не палиндром.
   * Ввод: `А!` -> Вывод: Не палиндром (так как знаки препинания сравниваются: `а!` не равно `!а`).

3. ** replace.py **: 

   * Ввод: `a::b:` -> Вывод: замен 3, Новая строка: `a--b-`.
   * Ввод: `abc` -> Вывод: замен 0, Новая строка: `abc`.

4. ** variant.py (Вариант 8) **: 

   * Контрольный ввод: `Анна, армия! Я читаю. Книга, край, рама..` 
     Вывод: `армия`, `читаю`, `книга`, `край`, Общее количество: 4.
   * Ввод: `!!!` -> Вывод: Нет совпадений, количество: 0.
   * Ввод: пустая строка -> Вывод: Нет совпадений, количество: 0.
