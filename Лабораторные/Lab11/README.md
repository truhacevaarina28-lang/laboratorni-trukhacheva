# Лабораторная работа №11

## Описание HTTP-части (`fetch_profile.py`):

* **Адрес запроса (URL):** `https://api.github.com/users/<логин>` — публичный REST API GitHub для получения базовой информации о пользователе в формате JSON.
* **Метод GET:** Используется по умолчанию при передаче объекта `Request` в `urlopen` — служит для безопасного чтения данных с сервера без их изменения.
* **Таймаут (`timeout=10`):** Ограничивает время ожидания ответа сервера 10 секундами, чтобы программа не зависла бесконечно при плохом соединении.
* **Обработчики ошибок:**
  * `HTTPError` — перехватывает коды ошибок сервера (например, `404` если пользователь не найден, `403` при превышении лимита запросов).
  * `URLError`, `TimeoutError`, `socket.timeout` — обрабатывают отсутствие интернета или обрыв связи.
  * `ValueError`, `UnicodeError` — защищают от битого JSON или некорректной кодировки ответа.
  * `OSError` — перехватывает ошибки записи файла на диск.
