# Лабораторная работа №7

## Описание тестов для Варианта 8:
В файле `test_functions.py` реализованы следующие проверки:
* Работа на контрольном списке `[-5, 0, 2, 5]` с порогом `2` (возвращает `[0, 2]`).
* Проверка пустого списка (возвращает `[]`).
* Проверка сохранения повторов элементов и включения точных границ условий (`-2` и `2` при пороге `2`).
* Проверка неизменяемости переданного в функцию списка.
