# Лабораторная работа №8

## Ответ на вопрос из Задания 3: Почему запись представлена словарём?

Запись (например, о курсе или поездке) удобно представлять словарём (`dict`), потому что у каждого свойства есть понятное текстовое имя — **ключ** (`"title"`, `"hours"`, `"completed"`). 
В отличие от списка, где пришлось бы запоминать, под каким числовым индексом лежит название, а под каким часы, словарь позволяет обращаться к данным по смыслу (`record["title"]`) и легко добавлять новые поля в любой момент (как мы добавили ключ `"completed"`).
