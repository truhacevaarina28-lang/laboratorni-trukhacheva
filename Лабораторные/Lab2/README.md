## Задание 3. 

| Выражение     | Мой ручной прогноз | Результат питона | Объяснение                                                                          |
| :---          | :---               | :---             | :---                                                                                |
| `2 + 3 * 4`   | 14                 | 14               | Сначала выполняется умножение (3*4=12), затем сложение (+2).                        |
| `(2 + 3) * 4` | 20                 | 20               | Скобки меняют приоритет: сначала сумма (2+3=5), потом умножение (*4).               |
| `17 // 5`     | 3                  | 3                | Целочисленное деление. 5 помещается в 17 ровно 3 раза.                              |
| `17 % 5`      | 2                  | 2                | Остаток от деления 17 на 5 (17 - 15 = 2).                                           |
| `-7 // 2`     | -4                 | -4               | Округление вниз до ближайшего меньшего целого. -3.5 округляется до -4.              |


## Индивидуального варианта №8 ручной расчет:

* Общее количество заданий: 25
* Заданий в комплекте: 7

**Ожидаемые расчеты:**

* Полных комплектов: 25 // 7 = 3
* Остаток заданий: 25 % 7 = 4
* Минимально комплектов всего: (25 + 7 - 1) // 7 = 31 // 7 = 4
