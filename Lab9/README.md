* **Суммы строк и столбцов:** Проверены на матрицах `2x3`, `1x1`, `3x1` и пустом списке `[]`.
* **Диагональный узор:** Для `size = 3` формирует матрицу с `0` на главной диагонали, `1` выше (`row < col`) и `2` ниже (`row > col`).
